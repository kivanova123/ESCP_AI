# Dino Dash

A self-contained browser game built with HTML, CSS, and vanilla JavaScript.

## Play locally

Open [index.html](./index.html) in a browser.

## Controls

- **Space / Arrow Up** — jump
- **Arrow Down** — duck under flying obstacles
- **P** — pause or resume
- **Tap / click** — jump on touch devices

The best score is saved in the browser with `localStorage`.
